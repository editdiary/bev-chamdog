# Study 노트

프로젝트를 진행하며 **깊게 공부해야 하는 배경 지식**을 정리하는 폴더.
계획 문서가 "무엇을 어떤 순서로 할지"라면, 여기는 "그걸 이해하는 데 필요한 개념"을 다룬다.
모든 내용을 한 문서에 담기보다, **개념의 큰 그림 + 무엇을 검색/독서 하면 되는지의
가이드**를 지향한다.

## 문서 목록

- [`camera_models_and_calibration.md`](camera_models_and_calibration.md) — 카메라 투영
  모델(핀홀·어안)과 캘리브레이션의 큰 개념, 유명 모델들(KB, UCM, eUCM, Double Sphere,
  radial_poly 등)의 원리·장단점·툴 지원, 그리고 검색/독서 가이드.

## 작성 원칙

- **원리 우선:** 공식 암기보다 "왜 이런 모델이 필요한가"의 직관.
- **검색 가능하게:** 각 주제마다 구글/논문 검색어와 정평 있는 레퍼런스를 남긴다.
- **프로젝트 연결:** 배운 개념이 이 프로젝트(어안 4-cam BEV)의 어느 결정과 닿는지 표시.
