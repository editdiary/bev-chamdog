# 공통 지표 정의와 보고 규칙

논문 최종 실험 전체가 쓰는 지표다. 실험별 문서는 여기를 가리키고 정의를 반복하지 않는다.

---

## 1. 지표 정의

| 지표 | 뜻 | 방향 |
|---|---|---|
| **`iou_free`** | 예측한 free 영역과 정답 free 영역의 겹침 비율(IoU) | ↑ |
| **constant-map baseline** | 이미지를 **보지 않고** 학습 데이터의 칸별 다수결 free 지도 하나를 통째로 답으로 내는 대조군 | 기준 |
| **margin** | `iou_free` − baseline. **주 비교량** | ↑ |
| `fatal_rate` | 실제로 막힌 칸을 "갈 수 있다"고 답한 비율. 충돌로 이어지는 오류 | ↓ |
| `free_miss_rate` | 실제로 뚫린 칸을 "막혔다"고 답한 비율. 과도한 보수성 | ↓ |
| `f1@10/20/40cm` | 장애물 경계가 **라벨의** 경계와 그 거리 안에서 일치하는 정도 | ↑ |
| `range_mae` | 로봇 중심에서 각도별로 쏜 광선이 처음 막히는 거리의 절대 오차 [m] | ↓ |
| `range_bias` | 같은 광선 오차의 **부호 있는** 평균 [m] | 0에 가깝게 |
| `range_missed_obstacle_rate` | 그 광선이 장애물을 아예 놓친 비율 | ↓ |

모든 셀 지표는 동작점 **τ = 0.5**에서 잰다.

## 2. constant-map baseline이 왜 필수인가

온실은 통로 배치가 규칙적이라, **이미지를 전혀 보지 않고** "여기쯤은 대체로 뚫려 있더라"
지도 하나만 외워도 `iou_free`가 0.39~0.69까지 나온다(시퀀스에 따라 다르다).

그래서 `iou_free` 값 자체는 주장이 되지 못한다. **기준선을 얼마나 이겼는지(margin)가
주장이다.** 캠페인 규칙상 baseline 없이 `iou_free`를 단독 보고하지 않는다.

기준선은 학습 스크립트가 콘솔에만 찍고 TensorBoard에 남기지 않는다. 그래서 분석 단계에서
**학습과 같은 함수**(`constant_free_map` / `iou_free`)로 다시 계산한다. 값이 갈리지 않는다.

## 3. `range_bias` 부호 규약 — 뒤집히기 쉬운 곳

구현의 정의는 `dr = r_pred − r_gt`이고,

> **`dr > 0` = 장애물을 실제보다 멀다고 예측 = free 과대추정 = 위험한 쪽**

이다. 즉 **양수 `range_bias`는 안전에 불리하다.**

**다른 문헌은 같은 사건을 "장애물 거리의 과소추정"이라고 부른다.** `over`/`under`라는
단어만 옮겨 쓰면 부호가 뒤집혀 읽힌다. 논문에는 정의를 한 줄로 명시하고 쓴다.

## 4. 보고 규칙

| 규칙 | 이유 |
|---|---|
| `iou_free`는 **항상** baseline·margin과 함께 | §2 |
| 본문 문장도 "0.81 달성"이 아니라 "상수 지도 대비 +0.29" | §2 |
| `fatal_rate`·`free_miss_rate`는 **같은 동작점에서 한 쌍으로** | 문턱값을 옮기면 서로 반대로 움직인다. 하나만 좋아진 것을 "안전 개선"이라 부르면 안 된다 — 이 프로젝트에 같은 주장을 동작점 이동으로 철회한 전례가 있다 |
| `f1@Xcm`은 "라벨과의 일치도"라고 명시 | 라벨이 LiDAR + 사람 보정이다 ([`setup.md`](setup.md) §3) |
| **SD를 쓰고 SE를 쓰지 않는다** | 특히 LOSO fold는 학습 데이터를 6/7씩 공유해 독립 표본이 아니다. `SD/√7`은 표준오차가 아니다 |
| 소수 3자리, SD도 같은 자리 | 시드 SD가 0.002 수준이라 4자리는 표만 지저분해진다 |
| epoch 40 고정을 프로토콜로 선언, best-epoch은 각주 | 둘 차이가 실측 0.0007이라 각주 한 줄로 방어된다 |
| 시드 산포는 SD와 **n을 함께** | n=5임을 표 각주에 |

## 5. 본문에 꼭 넣을 단서

정직하게 먼저 밝히는 편이 리뷰에서 유리하다.

- **데이터가 작다** — 전체 267 프레임, 시퀀스 7개
- **라벨이 LiDAR + 사람 보정**이라 절대 경계 오차는 측정 불가. 경계 지표는 일치도다
- **fold 간 차이의 원인이 셋**(장면 난이도 · 표본 오차 · 라벨 품질)이고 분리할 수 없다.
  fold 차이를 "모델의 일반화 능력"만으로 읽지 않는다
- **LOSO fold는 독립 표본이 아니다** — 학습 데이터를 6/7씩 공유한다

## 6. 프로토콜을 섞지 않는다

고정 split과 LOSO는 학습 데이터 크기도 묻는 질문도 다르다. **하나의 평균으로 합치거나
직접 우열을 비교하지 않는다.** 두 프로토콜의 값이 우연히 비슷해도 마찬가지다.
